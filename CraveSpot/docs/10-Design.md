# Design System
**Project:** The Ultimate Cheat-Meal & Street Food Finder  
**Version:** 1.0

## 1. Design Direction
The interface should feel food-focused, simple, readable, and suitable for quick discovery on both desktop and mobile screens.

## 2. Color Tokens
| Token | Value | Usage |
|---|---|---|
| --color-primary | #f97316 | Primary actions and food-focused highlights |
| --color-primary-dark | #ea580c | Hover/emphasis |
| --color-success | #16a34a | Positive states |
| --color-warning | #ca8a04 | Pending/attention states |
| --color-error | #dc2626 | Errors |
| --color-bg | #ffffff | Page background |
| --color-surface | #f8fafc | Cards and panels |
| --color-text | #0f172a | Main text |

## 6. Accessibility
- Maintain readable contrast.
- Use semantic HTML.
- All form fields require visible labels.
- Images require meaningful alt text.
- Interactive elements must be keyboard accessible.
- Do not communicate important information through color alone.
- Provide clear validation and error messages.

## 7. Responsive Behavior
Design for:
- Mobile
- Tablet
- Desktop

Food cards should adapt from a multi-column desktop layout to a single-column mobile layout.
