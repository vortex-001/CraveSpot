Quick Start Guide for Testing:

---------------------------------------------------------------------
OPTION 1: AUTOMATIC 1-CLICK LAUNCH (WINDOWS)
---------------------------------------------------------------------
1. Double-click "setup.bat"
   - Automatically detects Python, creates clean venv, and installs packages.
   
2. Double-click "run_backend.bat"
   - Starts the Flask API server on http://localhost:5000.
   - Note: Works seamlessly with MySQL database, or uses rich built-in
     fallback data if MySQL is not installed on your machine!

3. Double-click "run_frontend.bat"
   - Starts the frontend server on http://localhost:5500 and opens your browser.

---------------------------------------------------------------------
OPTION 2: MANUAL COMMAND LINE (ANY OS)
---------------------------------------------------------------------
1. Install Python packages:
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On Mac/Linux:
   source venv/bin/activate
   pip install -r requirements.txt

2. Run Backend (Terminal 1):
   python backend/app.py

3. Run Frontend (Terminal 2):
   python -m http.server 5500 -d frontend

4. Open in browser:
   http://localhost:5500

---------------------------------------------------------------------
