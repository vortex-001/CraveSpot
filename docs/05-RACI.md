# RACI Matrix

**Project:** CraveSpot — Hyper-Local Restaurant Discovery & Intelligent Craving Recommendation Engine  
**Team:** The Confluence  

**Legend:**
- **R = Responsible:** The role that conducts the actual work.
- **A = Accountable:** The role with final approval and decision authority.
- **C = Consulted:** Roles that provide input and domain expertise.
- **I = Informed:** Roles that are updated on progress and results.
